# Flowly — Project Management SaaS Landing Page

Flowly adalah proyek landing page untuk platform manajemen proyek modern yang dirancang dengan estetika visual Hand-Drawn Style. Proyek ini dibuat sebagai portofolio pengembangan antarmuka web (frontend) yang responsif, interaktif, dan memiliki performa tinggi.

Dikembangkan oleh **M.Lie Ulin Nuha** (Founder awshopedia & Lvara.academy).

---

## Ringkasan Proyek

Landing page ini bertujuan untuk menyajikan informasi produk SaaS secara terstruktur dan menarik. Desain visual memanfaatkan pendekatan border asimetris dan kombinasi tipografi kustom untuk memberikan kesan kreatif namun tetap menjaga keterbacaan serta pengalaman pengguna yang optimal.

---

## Fitur Utama

- **Theme Switcher (Dark / Light Mode)**: Dukungan mode terang dan gelap berbasis variabel CSS yang responsif terhadap preferensi pengguna.
- **Dynamic Pricing Toggle**: Fitur pengubah skema harga antara pembayaran bulanan dan tahunan secara dinamis menggunakan JavaScript.
- **Testimonials Carousel**: Slider testimoni interaktif untuk menampilkan ulasan dari pengguna.
- **Interactive FAQ Accordion**: Komponen tanya jawab modular dengan animasi transisi yang halus.
- **Lead Capture Modal**: Dialog pop-up untuk pendaftaran awal pengguna atau uji coba gratis.
- **Responsive Navigation**: Navigasi seluler berbasis drawer yang disesuaikan untuk berbagai ukuran layar.
- **Scroll Animation**: Efek transisi elemen saat pengguna melakukan navigasi halaman.

---

## Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik dan aksosibel.
- **CSS3**: Sistem tata letak modern (Flexbox dan CSS Grid), variabel CSS, serta styling border kustom.
- **JavaScript (ES6+)**: Manipulasi DOM, penanganan event, dan logika interaktif tanpa library eksternal.
